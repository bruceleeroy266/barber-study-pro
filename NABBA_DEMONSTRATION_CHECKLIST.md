## 4. Troubleshooting Guide

### 4.1 Technical Issues

| Issue | Immediate Action | Backup Plan |
|-------|-----------------|-------------|
| Demo won't load | Check internet, restart browser | Switch to local server |
| Slow loading | Close other tabs, restart router | Use offline mode |
| Projector not working | Check cables, restart projector | Use laptop screen |
| Audio not working | Check volume, restart audio | Demo without audio |
| Laptop crash | Restart, reopen demo | Switch to backup device |
| Internet down | Switch to hotspot | Use offline mode/screenshots |

### 4.2 Demo Issues

| Issue | Solution |
|-------|----------|
| Forgot script | Refer to printed script, improvise |
| Demo too long | Skip to key points, offer follow-up |
| Demo too short | Extend with instructor portal, Q&A |
| Audience disengaged | Ask questions, involve them |
| Technical questions | "Let me follow up with our tech team" |
| Feature requests | "Great idea, I'll note that for our team" |

### 4.3 Difficult Situations

| Situation | Response |
|-----------|----------|
| Competitor bashing | "There are other solutions. We're focused on measurable outcomes." |
| Price objection | "Consider the cost of a student dropping out vs. our platform." |
| Time waster | "I don't want to keep you. Here's a one-pager — reach out if interested." |
| Rude attendee | Stay professional, offer materials, move on |
| Overly technical | "I'd love to connect you with our technical team after the conference." |
