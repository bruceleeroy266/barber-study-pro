## Confirmed Decisions

### DEC-001: Repository of Record

| Field | Value |
|-------|-------|
| **Decision** | Git repository is the official source of truth |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Version control, permanence, and integration with existing development workflow |
| **Impact** | All approved documents must be promoted to Git repository |

### DEC-002: Drafting Environment

| Field | Value |
|-------|-------|
| **Decision** | OpenClaw workspace is the drafting environment |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Enables AI-assisted drafting, rapid iteration, and preservation of evolution |
| **Impact** | All drafts, reviews, and revisions occur in workspace before promotion |

### DEC-003: Document Lifecycle

| Field | Value |
|-------|-------|
| **Decision** | Documentation follows the lifecycle: Draft → Review → Revision → Approved → Archived |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Ensures quality control and clear status tracking |
| **Impact** | All documents must track status; only Approved documents may be promoted |

### DEC-004: Promotion Rule

| Field | Value |
|-------|-------|
| **Decision** | Only approved documents are promoted to the Git repository |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Maintains repository integrity and trust |
| **Impact** | Repository contains only finalized, owner-approved content |

### DEC-005: Discovery Process

| Field | Value |
|-------|-------|
| **Decision** | Brand Discovery will be completed section by section |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Ensures thoroughness and allows focused attention on each element |
| **Impact** | No section is finalized until explicitly approved; all work is preserved |

### DEC-006: Truth Standard

| Field | Value |
|-------|-------|
| **Decision** | No assumptions or generated facts are to be treated as company truth without approval |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Maintains accuracy and prevents fictional content from becoming official |
| **Impact** | All content marked as Pending until verified and approved |

### DEC-007: Temporal Separation

| Field | Value |
|-------|-------|
| **Decision** | Separate current facts from future aspirations throughout the documentation |
| **Date** | 2026-08-06 |
| **Authority** | Gabriel Arcaina |
| **Rationale** | Prevents confusion between present state and vision; enables honest assessment |
| **Impact** | All documents must clearly label current vs. aspirational content |
