# C13-4 — 45-Question Assessment Audit & Repair

## Scope

C13-4 independently audits the existing Chapter 13 45-question assessment against **Milady Standard Barbering Chapter 13, printed pages 338–354**.

This was not an answer-choice shuffle.

Every item was reviewed for:

- source support
- stable concept alignment
- question clarity
- correct answer
- distractor plausibility
- explanation accuracy
- difficulty
- medical/safety scope
- jurisdictional overreach
- source-proximate wording
- answer-position bias
- answer-length bias

## Pre-audit defect

The C13-0 baseline proved:

- 45 questions
- A = 45
- B = 0
- C = 0
- D = 0

The old source comments also described the answer order as randomized/natural even though every persisted key was A.

## Post-audit result

- Questions: **45**
- Stable IDs: **45/45 preserved**
- Order indexes: **1–45 preserved**
- Canonical concept mappings: **45/45 preserved**
- Duplicate question stems: **0**
- Answer positions:
  - A = **12**
  - B = **11**
  - C = **11**
  - D = **11**
- Difficulty:
  - Easy = **15**
  - Medium = **20**
  - Hard = **10**

- Moderate answer-length bias (correct > longest distractor by 15+ chars): **0**
- Strong answer-length bias (correct > longest distractor by 25+ chars): **0**

The balanced key distribution is a consequence of item-level review and intentional key placement after the items were rewritten. It is not the evidence used to decide which answer is correct.

## High-risk repairs

### Medical / pseudofolliculitis scope

Questions 011–014 now teach curly-hair and ingrown-hair risk without asking a barber to diagnose or treat folliculitis/keloid conditions.

Question 014 is an application/scope decision rather than the old claim that untreated ingrown hairs "initiate" a keloid condition.

### Safety / blood exposure

Question 010 now tests the response to visible blood: stop and follow standard precautions and the applicable exposure incident procedure.

### Grain and 14-area reasoning

Questions 015–020 preserve source-supported grain, grain-change, growth-pattern, and 14-area concepts while testing whether the learner can override the default training map when the client's actual growth differs.

### Razor handling and control

Questions 021–037 preserve source-supported razor positions, body positioning, grip principles, skin stretching, shallow blade angle, stroke length, and dry support-hand concepts.

Procedural wording was rewritten in ASCYN PRO language rather than copied from source tables.

### Shave types

Questions 038–042 preserve preparation/shaving/finishing, first-time-over, second-time-over, once-over, and close-shave distinctions.

Question 042 no longer claims that against-grain shaving automatically causes infection. It tests client-specific risk and professional judgment.

### Facial-hair design

Questions 043–045 no longer require rigid face-shape prescriptions. They test consultation, proportion, natural growth, maintenance needs, and gradual beard trimming.

## Answer-length adversarial review

After the first C13-4 repair, an independent audit found a new test-taking shortcut: 42/45 correct answers were the longest option.

C13-4 therefore performed a second distractor/answer-length pass.

Final result:

- only 12/45 correct answers are longest
- no correct answer exceeds every distractor by 15+ characters
- no correct answer exceeds every distractor by 25+ characters

This avoids replacing the original "always A" shortcut with a "pick the longest answer" shortcut.
