# C5 Flashcard Book-Alignment Audit — 70-Card Baseline

## Scope
Source basis: connected Drive `chapter 5.pdf` and the matching Chapter 5 source artifact used for the LO1–LO18 lesson lock.

This audit does **not** edit the flashcard bank or the 50-question quiz. It classifies the existing `fc-5-001..070` bank before implementation.

## Audit rules
Each existing card is assigned one of two implementation dispositions:
- **RETAIN** — useful as written or close enough to preserve without a source-driven rewrite.
- **REWRITE** — keep the stable card ID, but replace the prompt/answer so it reflects the Chapter 5 source terminology, organization, or procedure more faithfully.

A separate **SUPPLEMENT** plan adds new cards only where the source contains important objectives that cannot be represented adequately by rewriting existing weak/duplicative cards.

## Baseline result
- Existing cards: **70**
- RETAIN: **37**
- REWRITE: **33**
- Current source-book coverage is strongest in specialty shears, basic clipper/trimmer use, razor grinds, thermal safety, and general station safety.
- Highest source-alignment gaps: **LO2, LO3, LO7, LO9, LO10, LO11, LO16, LO17, LO18**.
- Major architecture gap: Chapter 5 currently has no dedicated unseen reassessment reserve; that remains a later remediation phase and is not changed by this audit.
