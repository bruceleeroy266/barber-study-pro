# C5 Book Alignment — 18-Objective Gap Matrix

## Source basis
Primary source: the 29-page Chapter 5 PDF in connected Google Drive, `chapter 5.pdf` (Implements, Tools, and Equipment).

The source groups several learning objectives together (for example LO3 & LO4, LO5 & LO6, LO7 & LO8, LO10 & LO11, LO12–LO15, and LO17 & LO18). This matrix decomposes those grouped source sections into 18 coverage targets while preserving the source chapter's organization and terminology.

ASCYN PRO uses the source chapter for **coverage, terminology, sequence, and technical scope**. Production lesson wording, examples, scenarios, flashcards, and questions remain original ASCYN PRO content rather than copied textbook prose.
