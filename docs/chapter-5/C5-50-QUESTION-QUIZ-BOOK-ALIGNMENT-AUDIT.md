## Assessment-hardening rules for the next phase
When implementation begins, every rewritten question must:
1. stay at exactly one primary Chapter 5 concept family
2. be `hard` unless a lower difficulty is justified by source-essential recall
3. use plausible same-domain distractors
4. use BEST / FIRST / MOST / LEAST / NOT / EXCEPT only when the distinction is genuinely supported
5. teach the five-step test strategy in the explanation:
   - Read carefully
   - Identify the keyword
   - Eliminate wrong answers
   - Apply safety/procedure logic
   - Make the best remaining choice
6. avoid copied textbook wording
7. avoid manufacturer-specific absolutes unless the stem explicitly provides that manufacturer context
8. preserve `qq-5-001..050` IDs and the 50-question bank size
9. retain answer-key validity after any display shuffling
10. add LO1–LO18 coverage and duplicate-answer/ambiguity certification before moving to remediation

## Implementation decision
**Do not add question 51+.** The source can be covered by reclaiming weak, duplicate, and off-objective slots inside the existing 50-question bank.

The next implementation phase should rewrite the 30 flagged IDs, preserve the 20 retained questions, update concept mappings only where a rewritten question changes primary family, and add adversarial source-alignment tests before changing remediation.
