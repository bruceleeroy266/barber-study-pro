# ASCYN PRO Anti-Cheating To-Do

Status: Deferred until current site maintenance is complete.

## Planned anti-cheating work

- Randomize question order for each student attempt.
- Randomize answer-choice order.
- Use larger question pools so students do not receive identical quizzes.
- Keep Instructor Quiz Approval as an access gate.
- Add optional quiz availability windows.
- Add reasonable per-chapter time limits.
- Add optional one-question-at-a-time mode.
- Add an option to prevent backward navigation on higher-stakes assessments.
- Delay correct-answer review until the attempt is closed or released by the instructor.
- Add retake limits.
- Generate a different question set on retakes.
- Track suspicious attempt patterns, including:
  - unusually fast completion
  - repeated tab/focus loss
  - highly similar answer sequences
  - unusual retake patterns
  - rapid answers on difficult questions
- Add an instructor Attempt Activity view with:
  - start time
  - finish time
  - total duration
  - question count
  - tab/focus-loss events
  - approval status
- Add an instructor suspicious-activity dashboard.
- Add optional Secure Exam Mode for higher-stakes exams and the 110-question final.
- Treat copy/paste, right-click, screenshot, and developer-tool blocking only as minor deterrents, not primary security controls.

## Recommended implementation order

1. Question and answer-choice randomization
2. Delayed answer review
3. Timed attempts
4. Retake limits and regenerated question sets
5. Attempt activity logging
6. Instructor suspicious-activity dashboard
7. Optional Secure Exam Mode
