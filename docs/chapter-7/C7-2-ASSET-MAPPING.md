# C7-2 — Asset-to-Concept Mapping & Micro-Knowledge-Check Placement

## Scope

C7-2 maps the current Chapter 7 instructional and assessment assets before any content rewrite.

No lesson copy, flashcard wording, quiz wording, keyed answers, or explanations are changed in this phase.

## Inventory

- Active premium flashcards: 80
- Premium quiz questions: 50
- Canonical concept families: 10
- Planned micro-check placements: 10

## Mapping rules

1. Every active flashcard has exactly one primary Chapter 7 concept family.
2. Every Chapter 7 quiz question has exactly one primary concept family.
3. Cross-cutting safety relevance does not create duplicate grading evidence. A question has one primary family.
4. Micro-checks are placed after meaningful instructional sections, not after every screen.
5. Each concept family receives one planned micro-check placement with 1–3 questions.
6. Micro-check wording is deferred until content hardening verifies source accuracy.
7. Existing content remains audit material; mapping does not certify factual correctness.

## Diagnostic purpose

The map enables C7-3 to answer:

- Which concepts are over-represented?
- Which concepts lack enough independent assessment evidence?
- Which questions are too easy or recall-heavy?
- Which questions contain unsafe or unsupported absolutes?
- Which flashcards teach content that the lesson does not support?
- Where should hard application/scenario questions replace trivia?

C7-2 closes only when:

- 80/80 active flashcards are mapped exactly once
- 50/50 quiz questions are mapped exactly once
