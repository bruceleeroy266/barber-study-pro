# C14-2 — Source-Grounded Lesson Hardening

C14-2 reviews the existing Chapter 14 lesson without rewriting its 64-section teaching structure.

## Source boundary

The available ASCYN PRO Milady-aligned terminology guide supports Chapter 14 vocabulary such as blow-dry styling, crew cut, fade, flat top, taper, texturizing, and related haircutting/styling terminology. It also defines clipper guards as attachments used to reduce the amount of hair cut.

The available guide is explicitly a paraphrased study glossary and directs learners to the textbook for source wording. It does **not** establish a universal practical-exam rule for clipper guards. No current full Milady Chapter 14 textbook pages were available in the project source set used for this pass.

Therefore C14-2 uses the available source to preserve supported subject matter while removing or narrowing claims that the available source does not justify.

## Repairs made

- removed the subtitle promise of “board-exam mastery”
- changed the guard section from “State Board Critical” to tool-selection instruction
- preserved the difference between detachable blades, guards, and freehand clipper technique
- replaced the universal guard/practical-exam prohibition with a jurisdiction/provider-specific verification rule
- removed the checkpoint claim that guard prohibition guarantees exam confidence / first-attempt passing
- removed the universal 6–12 month lock-development timeline
- removed the claim that locks are universally permanent
- removed the “only non-petroleum-based oils” absolute
- narrowed razor-cutting “best method” language into conditional technique guidance
- narrowed the absolute long-neck/natural-hairline design rule into a visual-design recommendation

## Preserved architecture

- 64 / 64 lesson section IDs preserved
- interactive section structure preserved
- C14-1 concept mappings remain stable
- no flashcard or assessment content changed in C14-2
- no textbook wording was copied

## Deferred

C14-3 and C14-4 must separately repair any flashcard or assessment item that still repeats claims removed from the lesson. In particular, the Chapter 14 flashcard/quiz state-board guard claim and lock timing/product absolutes remain outside the lesson-hardening scope until those phases.
