## License Stage Structure

North Carolina maintains separate examination requirements associated with different barber licensing stages.

### Apprentice Barber

| Component | Required | Confidence |
|-----------|----------|------------|
| **Written Examination** | Yes | CONFIRMED |
| **Practical Examination** | Yes | CONFIRMED |
| **Written Exam CIB/Material** | Yes | CONFIRMED |

### Licensed Barber

| Component | Required | Confidence |
|-----------|----------|------------|
| **Practical Examination** | Yes | CONFIRMED |

**Note:** Current terminology replaces the older "registered barber" terminology with "licensed barber."

"Master Barber" may also appear informally/secondarily in related discussion, but preserve the Board's current terminology.

## Architecture / Research Implication

North Carolina reinforces:

```
State → Profession → License Stage → Examination Requirement
```

rather than:

```
State → Barber Exam
```

This is consistent with the Kentucky multi-stage model identified in Batch 2.
