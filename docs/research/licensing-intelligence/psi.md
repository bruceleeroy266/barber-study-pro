# PSI — Examination Services

**Organization:** PSI Services LLC  
**Role:** Exam Developer + Exam Administrator (varies by jurisdiction)  
**Research Date:** 2026-08-14  
**Status:** CONFIRMED — Initial research complete

---

## Overview

PSI is a comprehensive examination services provider that can serve multiple roles depending on the jurisdiction:
- Examination administration
- Examination infrastructure
- PSI-developed national examination content

---

## Role Complexity

**Critical Finding:** PSI can play more than one role depending on the jurisdiction.

| Role | Description | Example |
|------|-------------|---------|
| **Administrator Only** | Delivers exams developed by others | Some states |
| **Developer + Administrator** | Creates and delivers exams | Texas Class A Barber |
| **Infrastructure Provider** | Testing platform only | Various |

**Therefore:** `PSI` should not automatically mean one specific examination blueprint.

---

## PSI-Developed Examinations

PSI develops national examination content for certain programs. The exact blueprint varies by:
- State
- License type
- Examination program
- Version

---

## State Examples

### Texas

| Aspect | Value |
|--------|-------|
| **License** | Class A Barber |
| **Exam Developer** | PSI |
| **Exam Administrator** | PSI |
| **Blueprint** | Texas-specific |

**Finding:** Texas uses PSI for examination administration AND maintains examination/CIB information specific to its Class A Barber licensing structure.

**Implication:** Must research the actual examination associated with each state rather than infer the blueprint solely from the administrator.

---

## ASCYN PRO Implication

**Key Finding:** PSI's role varies by jurisdiction.

When researching a state:
1. Determine if PSI is administrator, developer, or both
2. If PSI-developed, identify the specific examination program
3. Obtain the current CIB and version
4. Track state-specific customizations

**Do NOT assume:** PSI = universal blueprint.
