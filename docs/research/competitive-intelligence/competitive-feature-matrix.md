## Key Takeaways

1. **Exam-blueprint alignment alone is not sufficient differentiation** — Milady and Pivot Point both offer CIB/exam-aligned preparation.
2. **Generic Detect → Alert → Intervene is not sufficient differentiation** — CourseKey already provides retention risk and intervention workflows.
3. **ASCYN PRO's potential differentiation** lies in the instructor-centered workflow: Learning Gap → Instructor Action → Targeted Remediation → Follow-Up → Evidence of Improvement.
4. **AI Tutor / Remediation** is not confirmed in competitor public sources — potential differentiator, but requires validation.
