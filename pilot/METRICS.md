## Metric Definitions

| Metric | Definition | Source |
|---|---|---|
| Active Users | Unique users who logged in | Supabase Auth |
| Login Success | Successful logins / total attempts | Application logs |
| Support Requests | Number of support tickets | Manual tracking |
| Bugs Opened | New bugs reported | BUG_TRACKER.md |

| Feature Requests | New feature requests | FEATURE_REQUESTS.md |
| Deployments | Production deployments | Vercel |
| Session Duration | Average time per session | Analytics |
| Completion Rate | Users completing workflows | Application data |
| Satisfaction Score | User survey rating | Surveys |
