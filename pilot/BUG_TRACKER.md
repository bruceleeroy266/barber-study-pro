# ASCYN PRO - Pilot Bug Tracker

**Purpose:** Track all bugs reported during pilot operations.

---

## Template

| ID | Date | Severity | Reported By | Description | Root Cause | Resolution | Status |
|---|---|---|---|---|---|---|---|
| BUG-001 | YYYY-MM-DD | Critical/High/Medium/Low | Name/Role | Brief description | Technical cause | Fix applied | Open/In Progress/Resolved/Closed |

---

## Severity Definitions

| Severity | Definition | Response Time |
|---|---|---|
| Critical | System down, data loss, security breach | Immediate |
| High | Major feature broken, significant user impact | < 24 hours |
| Medium | Feature partially broken, workaround exists | < 1 week |
| Low | Minor issue, cosmetic, no user impact | Backlog |

## Guidelines

1. **Assign unique ID** — Format: BUG-NNN
2. **Set severity immediately** — Use definitions above
3. **Document root cause** — Technical explanation
4. **Track resolution** — Commit SHA, deployment date
5. **Close when verified** — Confirm fix in production
